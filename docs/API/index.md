# API

Welcome to `MetroGYM`'s API where you will find all references to the available public modules, parameters, examples, and more.

??? warning "Documentation Under Alpha Construction"
    Some API reference pages are still being refined. If something looks incomplete or outdated, please [open an issue](https://github.com/larrywhizz767-png/MetroGYM/issues).

<div class="grid cards" markdown>

- __Foundations__

    ---

    The foundation objects help you define systems, coordinates, colours, assets, and core visual modes before running any downstream simulation workflow.

    [Jump to primitives](foundations/metro-system.md)

- __Primitives__

    ---

    The `primitives` are designed to declare metro infrastructure, rolling stock, signalling, and optional queueing components.

    [Jump to primitives](primitives/network.md)

- __Solvers__

    ---

    `Solvers` are designed to inspect world state and return typed train or signal decisions.

    [Jump to primitives](solvers/world-views-and-decisions.md)

- __Rendering__

    ---

    The `rendering` entry points help you display the fitted world and configure the public renderer surface.

    [Jump to primitives](rendering/renderer-primitive.md)

</div>
